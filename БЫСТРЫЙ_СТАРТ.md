## Минимальная инструкция для опытных пользователей

### 1. Установка (1 минута) - ПОЛНАЯ ВЕРСИЯ ✅
```bash
# ✅ Клонируйте ПРАВИЛЬНУЮ ветку (полная версия с 244 файлами)
git clone -b copilot/fix-bot-start-issues https://github.com/tsepper002/arbitrage-bot.git
cd arbitrage-bot

# ❌ НЕ используйте обычный clone - получите базовую версию (51 файл)
# git clone https://github.com/tsepper002/arbitrage-bot.git

# Установите зависимости
pip install -r requirements.txt
```

### 2. Первый запуск - Тестовый режим (30 секунд)
```bash
# Запустите бота в режиме симуляции (безопасно)
python main.py
```

Бот подключится к 5 биржам и начнёт искать арбитраж. Нажмите `Ctrl+C` для остановки.

### 3. Настройка для реальной торговли (3 минуты)

```bash
# Скопируйте шаблон конфигурации
copy .env.example .env   # Windows
# cp .env.example .env   # Linux/macOS

# Откройте .env и вставьте свои API ключи
notepad .env  # Windows
# nano .env   # Linux/macOS
```

Минимальная конфигурация для старта:
```bash
# Обязательно заполните API ключи от бирж
ARB_BYBIT_KEY=ваш_ключ
ARB_BYBIT_SECRET=ваш_секрет
# ... и так для каждой биржи (Bybit, KuCoin, HTX, XT, MEXC)

# Для реальной торговли измените:
ARB_DRY_RUN=false

# Лимиты риска (рекомендуется)
ARB_MAX_DAILY_LOSS=50.0
ARB_MAX_EXPOSURE_USDT=200.0
```

### 4. Запуск в боевом режиме
```bash
python main.py
```

## Получение API ключей

**Минимальный набор** - API ключи хотя бы от 2 бирж:

- **Bybit**: https://www.bybit.com → API Management → Create (Spot Trading)
- **KuCoin**: https://www.kucoin.com → API Management → Create (Spot + Passphrase!)
- **HTX**: https://www.htx.com → API Management → Create (Trade)
- **XT**: https://www.xt.com → API Management → Create (Spot Trading)
- **MEXC**: https://www.mexc.com → API Management → Create (Spot Trading)

```powershell
.\watchdog.ps1
```

Настройте Task Scheduler для автозапуска при старте Windows (инструкция в `ИНСТРУКЦИЯ.md`).

## Решение проблем

**ModuleNotFoundError**: `pip install -r requirements.txt`

**WebSocket не подключается**: Проверьте интернет, отключите антивирус

**Authentication failed**: Проверьте правильность API ключей в `.env`

**Не находит арбитраж**: Это нормально, арбитраж редок. Понизьте `ARB_MIN_NET_ROI_PCT=0.03`

## Telegram уведомления (опционально)

1. Создайте бота через @BotFather в Telegram
2. Получите токен и chat_id
3. Добавьте в `.env`:
   ```bash
   ARB_TELEGRAM_TOKEN=ваш_токен
   ARB_TELEGRAM_CHAT_ID=ваш_chat_id
   ```

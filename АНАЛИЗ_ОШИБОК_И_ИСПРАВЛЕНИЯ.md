## ❌ ОБНАРУЖЕННЫЕ ОШИБКИ

### 1. DNS Timeout Errors (КРИТИЧЕСКАЯ ПРОБЛЕМА)

**Симптомы:**
```
ERROR: Cannot connect to host api.bybit.com:443 ssl:default 
[Timeout while contacting DNS servers]
```

**Затронутые сервисы:**
- ✅ Bybit REST API - не может загрузить баланс
- ✅ KuCoin REST API - не может загрузить баланс
- ✅ HTX REST API - не может загрузить баланс  
- ✅ MEXC REST API - не может загрузить баланс
- ✅ Telegram API - не может отправить сообщения

**Root Cause:** 
- `aiodns` библиотека не может резолвить DNS имена
- Возможно проблемы с локальной сетью/DNS/firewall
- IPv4 enforcement уже добавлен но недостаточно

**Влияние:**
- Баланс = $0.00 (не может загрузить)
- Telegram не работает
- Предупреждения при startup validation

### 2. Binance WebSocket HTTP 451

**Симптомы:**
```
ERROR: Binance WebSocket error: server rejected WebSocket connection: HTTP 451
```

**Root Cause:**
- HTTP 451 = "Unavailable For Legal Reasons"
- Географические ограничения Binance
- Возможно пользователь в ограниченной юрисдикции

**Влияние:**
- Binance WebSocket не подключается
- Бот пытается переподключиться каждые 5 секунд (спам в логах)
- Binance данные недоступны

---

### 3. Balance = $0.00

**Симптомы:**
```
No balance data available
Total balance $0.00 is below minimum $10.00
```

**Root Cause:**
- Следствие проблемы #1 (DNS timeout)
- Не может загрузить реальные балансы из-за сетевых ошибок

**Влияние:**
- Предупреждение о низком балансе
- В DRY_RUN режиме это не критично но мешает тестированию

## 💡 РЕКОМЕНДАЦИИ ДЛЯ ПОЛЬЗОВАТЕЛЯ

### Решение DNS Проблем:

1. **Проверить DNS настройки Windows:**
   ```powershell
   ipconfig /all
   # Check DNS servers
   ```

2. **Изменить на Google DNS:**
   ```
   Preferred DNS: 8.8.8.8
   Alternate DNS: 8.8.4.4
   ```

3. **Проверить Firewall/Antivirus:**
   - Добавить Python в исключения
   - Разрешить исходящие соединения

4. **Проверить VPN/Proxy:**
   - Отключить временно для теста
   - Или настроить для Python

5. **Flush DNS Cache:**
   ```powershell
   ipconfig /flushdns
   ```

### Binance Ограничения:

- HTTP 451 = Bot недоступен в вашей стране
- Решения:
  1. Использовать VPN (но может нарушить ToS)
  2. Работать без Binance (3 других биржи достаточно)
  3. Исправить код чтобы не спамить reconnect

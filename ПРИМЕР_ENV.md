# Пример правильно заполненного .env файла

## 📋 Заполненный .env для тестового режима

Это пример файла `.env` с **реальными ключами** (измените на свои!).

### Для тестирования (DRY_RUN = true)

```bash
# ============================================================================
# РЕЖИМ РАБОТЫ
# ============================================================================
# true = тестовый режим (безопасно, не тратит деньги)
# false = боевой режим (РЕАЛЬНАЯ ТОРГОВЛЯ!)
ARB_DRY_RUN=true

# ============================================================================
# API КЛЮЧИ БИРЖ
# ============================================================================

# ----- Bybit -----
ARB_BYBIT_KEY=aBcDeFgHiJkLmNoPqRsTuVwXyZ123456
ARB_BYBIT_SECRET=xYz987654321AbCdEfGhIjKlMnOpQrStUvWx

# ----- KuCoin -----
ARB_KUCOIN_KEY=507f1f77bcf86cd799439011
ARB_KUCOIN_SECRET=7c4a8d09ca3762af61e59520943dc26494f8941b
ARB_KUCOIN_PASSPHRASE=MySecurePassword123

# ----- HTX (Huobi) -----
ARB_HTX_KEY=a1b2c3d4-e5f6-7890-abcd-ef1234567890
ARB_HTX_SECRET=12345678-90ab-cdef-1234-567890abcdef

# ----- XT -----
ARB_XT_KEY=xt_api_key_example_12345
ARB_XT_SECRET=xt_secret_example_67890

# ----- MEXC -----
ARB_MEXC_KEY=mx0vglABCDEF123456
ARB_MEXC_SECRET=1234567890abcdef1234567890abcdef

# ============================================================================
# TELEGRAM БОТ (ОПЦИОНАЛЬНО)
# ============================================================================
# Если не нужны уведомления - можно оставить пустым или закомментировать
ARB_TELEGRAM_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
ARB_TELEGRAM_CHAT_ID=123456789

# ============================================================================
# УПРАВЛЕНИЕ РИСКАМИ
# ============================================================================
# Минимальная прибыль для торговли (%)
ARB_MIN_NET_ROI_PCT=0.05

# Максимальная сумма одной сделки (USDT)
ARB_MAX_EXPOSURE_USDT=200.0

# Лимиты убытков
ARB_MAX_DAILY_LOSS=50.0        # Макс убыток за день ($)
ARB_MAX_HOURLY_LOSS=20.0       # Макс убыток за час ($)
ARB_MAX_SINGLE_TRADE_LOSS=15.0 # Макс убыток в одной сделке ($)

# ============================================================================
# ПРОИЗВОДИТЕЛЬНОСТЬ
# ============================================================================
# Частота сканирования (секунды)
ARB_SCAN_INTERVAL_SEC=0.5

# Торгуемые пары (через запятую, без пробелов!)
ARB_SYMBOLS=BTC-USDT,ETH-USDT,SOL-USDT,BNB-USDT,XRP-USDT

# Уровень логирования (DEBUG, INFO, WARNING, ERROR)
ARB_LOG_LEVEL=INFO
```

## 📋 Минимальный .env (только необходимое)

Если хотите запустить быстро с минимальными настройками:

```bash
# Тестовый режим
ARB_DRY_RUN=true

# API ключи хотя бы от 2 бирж (остальные можно оставить пустыми)
ARB_BYBIT_KEY=ваш_ключ_bybit
ARB_BYBIT_SECRET=ваш_секрет_bybit

ARB_KUCOIN_KEY=ваш_ключ_kucoin
ARB_KUCOIN_SECRET=ваш_секрет_kucoin
ARB_KUCOIN_PASSPHRASE=ваша_парольная_фраза

# Торгуемые пары
ARB_SYMBOLS=BTC-USDT,ETH-USDT

# Всё остальное будет использовать значения по умолчанию!
```

## 📋 .env для боевого режима

⚠️ **ВНИМАНИЕ**: Используйте только после тестирования!

```bash
# ============================================================================
# БОЕВОЙ РЕЖИМ
# ============================================================================
ARB_DRY_RUN=false  # ← РЕАЛЬНАЯ ТОРГОВЛЯ!

# ============================================================================
# API КЛЮЧИ (все 5 бирж)
# ============================================================================
ARB_BYBIT_KEY=ваш_реальный_ключ
ARB_BYBIT_SECRET=ваш_реальный_секрет

ARB_KUCOIN_KEY=ваш_реальный_ключ
ARB_KUCOIN_SECRET=ваш_реальный_секрет
ARB_KUCOIN_PASSPHRASE=ваша_реальная_парольная_фраза

ARB_HTX_KEY=ваш_реальный_ключ
ARB_HTX_SECRET=ваш_реальный_секрет

ARB_XT_KEY=ваш_реальный_ключ
ARB_XT_SECRET=ваш_реальный_секрет

ARB_MEXC_KEY=ваш_реальный_ключ
ARB_MEXC_SECRET=ваш_реальный_секрет

# ============================================================================
# TELEGRAM (ОБЯЗАТЕЛЬНО для боевого режима!)
# ============================================================================
ARB_TELEGRAM_TOKEN=ваш_реальный_токен
ARB_TELEGRAM_CHAT_ID=ваш_реальный_chat_id

# ============================================================================
# СТРОГИЕ ЛИМИТЫ РИСКА
# ============================================================================
ARB_MIN_NET_ROI_PCT=0.08           # Торговать только при >0.08% прибыли
ARB_MAX_EXPOSURE_USDT=100.0        # Небольшие сделки для начала
ARB_MAX_DAILY_LOSS=30.0            # Стоп при убытке $30/день
ARB_MAX_HOURLY_LOSS=15.0           # Стоп при убытке $15/час
ARB_MAX_CONSECUTIVE_LOSSES=3       # Пауза после 3 убытков подряд
ARB_MIN_BALANCE_PER_EXCHANGE=50.0  # Минимум $50 на бирже для торговли
```

## 🎨 Пример с комментариями на русском

```bash
# Этот файл - ваша главная конфигурация бота
# Каждая строка начинающаяся с # - это комментарий (игнорируется ботом)

# === РЕЖИМ РАБОТЫ ===
ARB_DRY_RUN=true  # true=тест, false=реальная торговля

# === BYBIT ===
# Получить ключи: https://www.bybit.com → API Management
ARB_BYBIT_KEY=ваш_api_ключ_bybit
ARB_BYBIT_SECRET=ваш_secret_ключ_bybit

# === KUCOIN ===
# Получить ключи: https://www.kucoin.com → API Management
# ВНИМАНИЕ: У KuCoin есть дополнительная парольная фраза!
ARB_KUCOIN_KEY=ваш_api_ключ_kucoin
ARB_KUCOIN_SECRET=ваш_secret_ключ_kucoin
ARB_KUCOIN_PASSPHRASE=ваша_парольная_фраза_придумайте_сами

# === HTX (бывший Huobi) ===
# Получить ключи: https://www.htx.com → API Management
ARB_HTX_KEY=ваш_access_key_htx
ARB_HTX_SECRET=ваш_secret_key_htx

# === XT ===
# Получить ключи: https://www.xt.com → API Management
ARB_XT_KEY=ваш_api_ключ_xt
ARB_XT_SECRET=ваш_secret_ключ_xt

# === MEXC ===
# Получить ключи: https://www.mexc.com → API Management
# MEXC имеет 0% комиссию для maker ордеров!
ARB_MEXC_KEY=ваш_api_ключ_mexc
ARB_MEXC_SECRET=ваш_secret_ключ_mexc

# === TELEGRAM ===
# Создать бота: найдите @BotFather в Telegram
ARB_TELEGRAM_TOKEN=ваш_токен_от_botfather
ARB_TELEGRAM_CHAT_ID=ваш_chat_id

# === ОСНОВНЫЕ НАСТРОЙКИ ===
ARB_MIN_NET_ROI_PCT=0.05        # Минимальная прибыль 0.05%
ARB_MAX_EXPOSURE_USDT=200.0     # Макс $200 на сделку
ARB_MAX_DAILY_LOSS=50.0         # Стоп если потеря >$50/день

# === ТОРГУЕМЫЕ ПАРЫ ===
# Список через запятую БЕЗ ПРОБЕЛОВ!
ARB_SYMBOLS=BTC-USDT,ETH-USDT,SOL-USDT,BNB-USDT,XRP-USDT

# === ЛОГИРОВАНИЕ ===
ARB_LOG_LEVEL=INFO  # DEBUG для подробных логов, INFO для обычных
```

## ✅ Как проверить правильность заполнения

После создания `.env` выполните:

```bash
python settings.py
```

### Правильный вывод:
```
=== Arbitrage Bot Configuration (ENHANCED) ===
Execution Mode: 🔵 DRY RUN (Safe)
Exchanges: Bybit, KuCoin, HTX, XT, MEXC (5 total)
Min Net ROI: 0.05%
Max Exposure: $200.0 USDT
...
✅ Configuration looks safe
```

### Если ошибка:
```
⚠️  Configuration Issues:
  ⚠️  Bybit API keys not set
  ⚠️  KuCoin API keys not set
```

Значит API ключи не загрузились - проверьте файл `.env`.

## 🚫 Типичные ошибки

### ❌ НЕПРАВИЛЬНО:

```bash
# Лишние пробелы
ARB_BYBIT_KEY = abc123
ARB_BYBIT_SECRET= xyz789

# Кавычки (не нужны!)
ARB_BYBIT_KEY="abc123"
ARB_BYBIT_SECRET='xyz789'

# Пробелы в значении
ARB_BYBIT_KEY=abc 123

# Пустые строки между переменными (это OK, но не обязательно)
ARB_BYBIT_KEY=abc123

ARB_BYBIT_SECRET=xyz789
```

### ✅ ПРАВИЛЬНО:

```bash
# Нет пробелов вокруг =
ARB_BYBIT_KEY=abc123
ARB_BYBIT_SECRET=xyz789

# Нет кавычек
ARB_TELEGRAM_TOKEN=123456789:ABCdefGHI

# Символы через запятую БЕЗ пробелов
ARB_SYMBOLS=BTC-USDT,ETH-USDT,SOL-USDT
```

## 🔍 Поиск и замена

Если у вас много ключей, используйте функцию "Найти и заменить" в редакторе:

1. Откройте `.env` в VS Code / Notepad++
2. Найти: `your_bybit_api_key_here`
3. Заменить на: ваш реальный ключ от Bybit
4. Нажмите "Заменить"
5. Повторите для каждого ключа

## 💡 Совет

**Создайте несколько .env файлов для разных режимов:**

```
.env              ← Текущая конфигурация (используется ботом)
.env.test         ← Для тестирования (DRY_RUN=true)
.env.production   ← Для боевого режима (DRY_RUN=false)
.env.backup       ← Резервная копия
```

Переключение между ними:
```bash
# Перейти на тестовую конфигурацию
copy .env.test .env

# Перейти на боевую конфигурацию
copy .env.production .env
```

**Готово! Теперь у вас есть правильно настроенный .env файл.** 🎉

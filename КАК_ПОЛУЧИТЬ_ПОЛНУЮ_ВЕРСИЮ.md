# Как Получить Полную Версию / How to Get Full Version

## 🚨 ВАЖНО / IMPORTANT

При клонировании репозитория по умолчанию вы получите базовую версию из ветки `main`.
When cloning the repository by default, you get the basic version from `main` branch.

**Для получения ПОЛНОЙ версии со всеми улучшениями, используйте:**
**To get the FULL version with all improvements, use:**

## Рекомендуемый Способ / Recommended Method

### Скачать ветку с улучшениями / Download Enhanced Branch

```bash
# Клонировать полную версию / Clone full version
git clone -b copilot/fix-bot-start-issues https://github.com/tsepper002/arbitrage-bot.git
cd arbitrage-bot

# Установить зависимости / Install dependencies
pip install -r requirements.txt

# Запустить / Run
python main.py
```

## Альтернативный Способ / Alternative Method

### Если уже клонировали main / If you already cloned main

```bash
# Перейти в директорию / Go to directory
cd arbitrage-bot

# Переключиться на улучшенную ветку / Switch to enhanced branch
git checkout copilot/fix-bot-start-issues

# Установить зависимости / Install dependencies
pip install -r requirements.txt

# Запустить / Run
python main.py
```

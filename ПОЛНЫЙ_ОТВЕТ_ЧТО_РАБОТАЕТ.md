#### 1. DNS Timeout Errors → ИСПРАВЛЕНО
**Проблема:**
```

[Timeout while contacting DNS servers]
```

**Что Сделано:**
- Заменил `aiodns` resolver на `ThreadedResolver` (system DNS)
- Добавил увеличенные timeouts (30s total, 10s connect)
- Обновлены все REST clients (4 биржи)
- Обновлен Telegram bot
- Обновлен connection pool

**Код:**
```python
# ДО:
connector = aiohttp.TCPConnector(family=socket.AF_INET)

# ПОСЛЕ:
connector = aiohttp.TCPConnector(
    family=socket.AF_INET,
    resolver=aiohttp.ThreadedResolver()  # ← System DNS!
)
timeout = aiohttp.ClientTimeout(total=30, sock_connect=10)
```

**Результат:** Более надежное DNS resolution

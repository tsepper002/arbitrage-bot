# Умное Распределение Капитала / Smart Capital Distribution

## Проблема / Problem

Пользователь запросил: **"надо сделать так, чтоб бот работал и с минимальными балансами, образно говоря от 8$ даже на одной из бирж, но также чтоб капитал и т.д распределялся в умном режиме"**

Translation: "Need to make the bot work with minimal balances, figuratively speaking from $8 even on one exchange, but also so that capital etc. is distributed in smart mode"

## Решение / Solution

Реализована система умного распределения капитала, которая позволяет торговать с балансами от **$8 на бирже**.

### Что Изменилось / What Changed

#### 1. Снижены Минимальные Требования / Lowered Minimums

**ДО / BEFORE:**
- Минимум на бирже: $20
- Минимум общий: $100
- Фиксированный размер сделки: до $500

**ПОСЛЕ / AFTER:**
- Минимум на бирже: **$8** (снижение на 62.5%)
- Минимум общий: **$10** (снижение на 90%)
- **Динамический размер** сделки: от $3 до $500+ в зависимости от баланса

#### 2. Новая Система Распределения / New Allocation System

Создан модуль `core/smart_capital_allocator.py` с интеллектуальным распределением:

**Основные Принципы:**
- 📊 **Пропорциональность** - больше баланс = больше сделка
- 🛡️ **Защита** - резерв $2 на каждой бирже
- ⚖️ **Баланс рисков** - максимум 60% баланса в одной сделке
- 🔄 **Адаптивность** - размер сделки подстраивается под баланс
- 🎯 **Согласование** - для арбитража использует меньший лимит

### Как Это Работает / How It Works

#### Пример 1: Минимальный Баланс ($8)

```
Баланс на Bybit: $8.00
├─ Резерв: -$2.00 (защита)
├─ Доступно: $6.00
├─ Макс использование (60%): $3.60
└─ Размер сделки: $3.60 ✅

Результат: Можно торговать!
```

#### Пример 2: Кросс-биржевой Арбитраж

```
Bybit: $8 → макс $3.60
KuCoin: $100 → макс $58.80

Для арбитража используется МЕНЬШИЙ лимит:
→ Размер сделки: $3.60 (ограничен Bybit)

Почему? Чтобы обе сделки выполнились полностью.
```

#### Пример 3: Разные Размеры Балансов

### Динамические Буферы Безопасности / Dynamic Safety Buffers

Система использует разные буферы в зависимости от размера баланса:

```python
Баланс < $50:    5% буфер  (гибкость для малых счетов)
Баланс $50-200:  10% буфер (стандартная защита)
Баланс > $200:   15% буфер (консервативность для больших)
```

### API Умного Распределения / Smart Allocation API

#### Использование в Коде / Usage in Code

```python
from core.smart_capital_allocator import get_smart_allocator

# Создать распределитель
allocator = get_smart_allocator(balance_manager)

# Получить доступный капитал
available = allocator.get_available_capital('bybit', 'USDT')
print(f"Available: ${available:.2f}")

# Рассчитать макс размер сделки
max_trade = allocator.calculate_max_trade_size('bybit')
print(f"Max trade: ${max_trade:.2f}")

# Распределить для арбитража
qty, info = allocator.allocate_for_arbitrage(
    buy_exchange='bybit',
    sell_exchange='kucoin',
    symbol='BTC/USDT'
)
print(f"Allocated: ${qty:.2f}")
print(f"Bottleneck: {info['bottleneck']}")

# Показать сводку
allocator.print_allocation_summary()
```

### Безопасность / Safety

#### Встроенная Защита / Built-in Protection

1. **Резервы** - всегда $2 на бирже
2. **Лимиты** - максимум 60% баланса
3. **Минимумы** - не менее $3 на сделку
4. **Буферы** - 5-15% в зависимости от размера
5. **Согласование** - для арбитража меньший лимит

#### Что Не Может Сделать Бот / Bot Cannot

❌ Использовать весь баланс (макс 60%)
❌ Торговать без резерва ($2 защищён)
❌ Сделки меньше $3 (не покроют комиссии)
❌ Превысить лимит одной биржи при арбитраже

### Часто Задаваемые Вопросы / FAQ

**Q: Почему минимум $8, а не $5?**
A: $8 = $2 резерв + $6 доступно × 60% = $3.60 сделка (выше минимума $3)

**Q: Можно ли торговать с $5?**
A: Технически да, но измените настройки:
```bash
ARB_MIN_BALANCE_PER_EXCHANGE=5.0
ARB_MIN_TRADE_SIZE_USDT=2.0
ARB_BALANCE_RESERVE_USDT=1.0
```
Но комиссии могут съесть прибыль!

**Q: Почему резерв $2?**
A: Защита от случайного опустошения счёта. Всегда есть запас.

**Q: Можно ли использовать 100% баланса?**
A: Можно установить `ARB_MAX_BALANCE_USAGE_PCT=100.0`, но ОПАСНО!
Рекомендуется 50-70%.

**Q: Как растут сделки с ростом баланса?**
A: Пропорционально. $8 → $3.60, $80 → $46.80, $800 → $478.80

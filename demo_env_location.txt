│

├── settings.py                      ← Проверка: python settings.py

Что делать:
-----------

1️⃣  Скопировать шаблон:
    copy .env.example .env

2️⃣  Открыть для редактирования:
    notepad .env

3️⃣  Вставить свои API ключи:
    ARB_BYBIT_KEY=ваш_настоящий_ключ
    ARB_BYBIT_SECRET=ваш_настоящий_секрет
    ...

4️⃣  Сохранить файл

5️⃣  Проверить:
    python settings.py

6️⃣  Запустить:
    python main.py


Важно:
------
✅ Файл .env должен быть В КОРНЕВОЙ ПАПКЕ (там же где main.py)
✅ Файл .env НЕ должен быть добавлен в Git (уже в .gitignore)
✅ Храните резервную копию .env в безопасном месте
❌ НИКОГДА не публикуйте .env на GitHub или где-либо ещё!

```
❌ Failed to fetch balance from Bybit: Cannot connect to host api.bybit.com:443 ssl:default [Could not contact DNS servers]
❌ Failed to fetch balance from KuCoin: Cannot connect...
❌ Telegram send error: Cannot connect to host api.telegram.org:443...
```

**ЭТО НЕ БАГИ КОДА!** Это проблема сети/DNS на компьютере пользователя.

### Решение:

1. **Проверьте интернет соединение**
2. **Измените DNS сервера:**
   - Google DNS: 8.8.8.8, 8.8.4.4
   - Cloudflare DNS: 1.1.1.1, 1.0.0.1
3. **Отключите VPN** если он блокирует
4. **Проверьте файрвол** Windows
5. **Перезагрузите роутер**

**Бот корректно обрабатывает эти ошибки и продолжает работу!** ✅

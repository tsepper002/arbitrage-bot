## ⚙️ МИНИМАЛЬНАЯ КОНФИГУРАЦИЯ .env

**Для ТЕСТОВОГО запуска (без реальной торговли):**

Откройте файл `.env` и добавьте ТОЛЬКО эту строку:

```bash
ARB_DRY_RUN=true
```

**Сохраните файл и запустите бота - он будет работать в безопасном режиме!**

## 💰 ДЛЯ РЕАЛЬНОЙ ТОРГОВЛИ

Откройте `.env` и добавьте API ключи ваших бирж:

```bash
# Режим работы
ARB_DRY_RUN=false

# Bybit
ARB_BYBIT_KEY=ваш_ключ_bybit
ARB_BYBIT_SECRET=ваш_секрет_bybit

# KuCoin
ARB_KUCOIN_KEY=ваш_ключ_kucoin
ARB_KUCOIN_SECRET=ваш_секрет_kucoin
ARB_KUCOIN_PASSPHRASE=ваш_пароль_kucoin

# HTX (Huobi)
ARB_HTX_KEY=ваш_ключ_htx
ARB_HTX_SECRET=ваш_секрет_htx

# MEXC
ARB_MEXC_KEY=ваш_ключ_mexc
ARB_MEXC_SECRET=ваш_секрет_mexc
```

## ⚠️ ЧАСТЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### Проблема: "python не найден"

**Windows:**
```powershell
py main.py
```

**Linux/macOS:**
```bash
python3 main.py
```

### Проблема: "pip не найден"

**Установите pip:**

Windows:
```powershell
py -m ensurepip --upgrade
```

Linux/macOS:
```bash
sudo apt install python3-pip  # Для Ubuntu/Debian
```

### Проблема: "ModuleNotFoundError"

**Переустановите зависимости:**
```bash
pip install -r requirements.txt --force-reinstall
```

### Проблема: "Permission denied"

**Linux/macOS:**
```bash
sudo pip3 install -r requirements.txt
```

### Проблема: Бот запускается но говорит "No API keys"

**Это нормально!** В режиме DRY_RUN API ключи не обязательны. Бот будет работать в тестовом режиме.

Если хотите реальную торговлю - добавьте API ключи в `.env` как показано выше.

## 🔍 КАК ПРОВЕРИТЬ ЧТО БОТ РАБОТАЕТ

**1. Проверьте что бот запустился:**
- Вы видите логи в консоли
- Нет ошибок ImportError или ModuleNotFoundError
- Видите сообщения "✅ ... initialized"

**2. Проверьте файлы:**
```bash
# Должен появиться файл состояния
ls -la bot_state.json

# Должен появиться лог-файл
ls -la arbitrage_bot.log
```

**3. Бот сканирует рынки:**
```
🔍 Scanning for arbitrage opportunities...
💡 Found opportunity: BTC/USDT ...
```

**Если видите это → БОТ ПОЛНОСТЬЮ РАБОТАЕТ!** ✅

## 🎯 ЧТО ДАЛЬШЕ?

**После успешного запуска:**

1. **В режиме DRY_RUN:**
   - Наблюдайте за работой бота
   - Смотрите найденные возможности
   - Изучайте логи

2. **Для реальной торговли:**
   - Добавьте API ключи в `.env`

   - Начните с малого капитала ($10-50)
   - Постепенно увеличивайте

3. **Мониторинг:**
   - Следите за логами: `tail -f arbitrage_bot.log`
   - Проверяйте файл состояния: `cat bot_state.json`
   - Смотрите баланс на биржах

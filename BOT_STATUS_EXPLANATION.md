## ❌ Что НЕ Работает (И Почему)

### ❌ Telegram Бот
**Проблема:**
```
ERROR: Cannot connect to host api.telegram.org:443 ssl:default
[Could not contact DNS servers]
```

**Причина:** Это НЕ баг в коде! Это проблема сети:
- DNS серверы недоступны
- Возможно VPN блокирует
- Возможно фаервол
- Возможно нет интернета

**Решение:**
1. Проверьте интернет-соединение
2. Отключите VPN или используйте другой
3. Проверьте настройки фаервола
4. Попробуйте изменить DNS (8.8.8.8, 1.1.1.1)

**Альтернатива:** Бот работает БЕЗ Telegram! Просто не будет отправлять уведомления.

### ❌ Балансы Бирж
**Проблема:**
```
ERROR: ❌ Failed to fetch balance from Bybit: Cannot connect...
ERROR: ❌ Failed to fetch balance from KuCoin: Cannot connect...
ERROR: ❌ Failed to fetch balance from HTX: Cannot connect...
ERROR: ❌ Failed to fetch balance from MEXC: Cannot connect...
```

**Причина:** ТА ЖЕ проблема с DNS!
- REST API запросы используют DNS
- DNS серверы недоступны
- Все 4 биржи не могут быть достигнуты

**Важно:** WebSocket подключения работают, потому что они уже установлены!

**Решение:** То же что для Telegram - исправить DNS/сеть

**Альтернатива:** В DRY RUN режиме балансы не нужны - бот симулирует сделки

## 📊 Как Понять Что Бот Работает

### Ищите эти сообщения:

1. **При старте:**
```
🚀 Starting arbitrage engine for 10 symbols
⚙️ Settings: MIN_ROI=0.05%, MAX_EXPOSURE=$200
📊 Waiting for price data from exchanges...
```

2. **Каждые 60 секунд:**
```
📊 STATUS: Scanning X/10 symbols across Y exchange connections
📡 Active exchanges: Bybit, KuCoin, HTX, MEXC
```

3. **Когда найдена возможность:**
```
💰 OPPORTUNITY: BTC-USDT | Buy KuCoin @ 68000 → Sell Bybit @ 68500 | ROI: 0.73% | Net: $50.00
```

4. **В DRY RUN режиме:**
```
🔵 DRY RUN: Would execute arbitrage...
```

### Если НЕ видите возможностей:

**Это НОРМАЛЬНО если:**
1. Рынок спокойный - нет больших разниц в ценах
2. Комиссии бирж съедают прибыль
3. MIN_ROI слишком высокий (по умолчанию 0.05%)
4. Недостаточная ликвидность

**Чтобы увидеть больше:**
- Уменьшите MIN_NET_ROI_PCT в settings.py (например, до 0.01%)
- Увеличьте количество символов
- Подождите волатильности на рынке

## 🔧 Настройки в settings.py

### Важные параметры:

```python
# Минимальная прибыльность для арбитража
MIN_NET_ROI_PCT = 0.05  # 0.05% - можно уменьшить до 0.01%

# Интервал сканирования
SCAN_INTERVAL_SEC = 0.5  # Как часто сканировать

# Максимальная экспозиция
MAX_EXPOSURE_USDT = 200.0  # Максимальный размер сделки

# Режим работы
DRY_RUN = True  # True = симуляция, False = реальные сделки

# Уровень логов
LOG_LEVEL = "INFO"  # DEBUG для подробных логов
```

## 📞 Если Всё Ещё Не Работает

### 1. Проверьте Логи
Ищите ERROR или WARNING сообщения

### 2. Проверьте Сеть
```powershell
ping 8.8.8.8
nslookup api.telegram.org
```

### 3. Уменьшите MIN_ROI
В settings.py: `MIN_NET_ROI_PCT = 0.01`

### 4. Включите DEBUG Логи
В settings.py: `LOG_LEVEL = "DEBUG"`

### 5. Подождите
Арбитражные возможности не постоянны - нужна волатильность

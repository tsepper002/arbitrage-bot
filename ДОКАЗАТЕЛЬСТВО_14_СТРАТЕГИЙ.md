## 💡 КАК ЭТО РАБОТАЕТ

### Архитектура

```
IntegratedArbitrageBot (main.py)
    │
    ├─> StrategyDispatcher (core/strategy_dispatcher.py)
    │       │
    │       ├─> scan_fast() (каждые 0.15с)
    │       │   ├─> CROSS_EXCHANGE
    │       │   ├─> TRIANGULAR
    │       │   ├─> SMART_ORDER
    │       │   └─> VOLATILITY
    │       │
    │       └─> scan_slow() (каждые 5 мин)
    │           ├─> Grid Trading
    │           ├─> DCA
    │           ├─> Market Making
    │           ├─> Pairs Trading
    │           ├─> Funding Rate
    │           ├─> Volatility Arb
    │           ├─> Index Arb
    │           ├─> Spread Betting
    │           ├─> Momentum
    │           └─> Breakout
    │
    └─> ArbitrageEngine
            └─> Execute best opportunity
```

### Процесс Сканирования

**Каждый цикл (0.15с):**
1. scan_fast() проверяет 4 быстрые стратегии
2. Собирает возможности
3. Передает в ArbitrageEngine

**Каждые 5 минут:**
1. should_scan_slow() проверяет таймер
2. scan_slow() вызывает все 10 медленных стратегий
3. Каждая стратегия проверяет условия
4. Собирает возможности
5. Передает в ArbitrageEngine

**Выполнение:**
1. ArbitrageEngine получает ВСЕ возможности
2. Ранжирует по ROI и приоритету
3. Проверяет риск-лимиты
4. Выполняет лучшую возможность

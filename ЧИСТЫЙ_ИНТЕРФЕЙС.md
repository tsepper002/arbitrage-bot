## 🎯 Как Понять Что Работает

### ✅ Биржи Работают:
```
📡 Active exchanges: Bybit, KuCoin, HTX, MEXC
```
- Показывает какие биржи активны
- Получают данные
- Обновляется каждые 60 секунд

### ✅ Сканирование Идет:
```
📊 STATUS: Scanning 10/10 symbols across 40 exchange connections
```
- 10/10 = все символы активны
- 40 connections = 10 символов × 4 биржи

### ✅ Возможности Находятся:
```
💰 OPPORTUNITY: BTC-USDT | Buy ... → Sell ... | ROI: 0.37% | Net: $25.47
```
- Когда найдена возможность
- Показывает детали
- В DRY RUN режиме симулирует

### ⚠️ Если Проблемы:
```
⚠️ No exchange data available in price store
```
- Значит биржи не подключены
- Проверьте интернет
- Проверьте VPN/DNS

## 🔧 Если Нужны DEBUG Логи

### Способ 1: Смотреть Файл
```powershell
# Windows
notepad logs\bot.log

# Или в реальном времени
Get-Content logs\bot.log -Wait
```

### Способ 2: Изменить Уровень Логирования
В файле `main.py` найдите:
```python
console_handler.setLevel(logging.INFO)
```

Измените на:
```python
console_handler.setLevel(logging.DEBUG)
```

**Но ВНИМАНИЕ:** Будет много спама в консоли!

## 🔧 INTEGRATION EXAMPLES

### Horizontal Scaler:
```python
from core.horizontal_scaler import get_horizontal_scaler

scaler = get_horizontal_scaler()

# Register instance metrics
scaler.register_instance("bot-1", metrics)

# Start auto-scaling
await scaler.auto_scale_loop()
```

### Message Queue:
```python
from core.message_queue import get_message_queue, TaskPriority

queue = get_message_queue(num_workers=4)
await queue.start()

# Register handler
queue.register_handler("execute_trade", trade_handler)

# Enqueue task
task_id = await queue.enqueue(
    task_type="execute_trade",
    payload={"symbol": "BTC/USDT"},
    priority=TaskPriority.HIGH
)
```

### Database Shard:
```python
from core.database_shard import get_database_shard

db_shard = get_database_shard()

# Add shards
db_shard.add_shard(shard_config)

# Insert with sharding
await db_shard.insert("trades", data, shard_key=symbol)

# Query with sharding
results = await db_shard.select("trades", shard_key=symbol)
```

### Load Balancer:
```python
from core.load_balancer import get_load_balancer

lb = get_load_balancer()

# Add instances
lb.add_instance(backend_instance)

# Start health checks
await lb.start_health_checks()

# Execute request
result = await lb.execute_request(request_func)
```

### Redis Cache:
```python
from core.redis_cache import get_redis_cache

cache = get_redis_cache()
await cache.start_cleanup()

# Get/Set pattern
value = await cache.get("spread:BTC/USDT")
if value is None:
    value = calculate_spread()
    await cache.set("spread:BTC/USDT", value, ttl=60)

# Get-or-set pattern
value = await cache.get_or_set(
    "orderbook:ETH/USDT",
    factory=fetch_orderbook,
    ttl=30
)
```

# Руководство по Управлению Биржами (Exchange Management Guide)

## 🎯 Обзор

Exchange Manager позволяет динамически добавлять и удалять биржи без перезапуска бота.

## 📊 Поддерживаемые Биржи

1. **Bybit** - Высокая ликвидность, низкие комиссии
2. **KuCoin** - Широкий выбор пар, хорошие объёмы
3. **HTX** (Huobi) - Азиатский лидер, низкие комиссии
4. **MEXC** - Большой выбор альткоинов
5. **Binance** - Крупнейшая биржа, максимальная ликвидность
6. **Coinbase** - Регулируемая, институциональная
7. **Gate.io** - 1000+ торговых пар
8. **OKX** - Деривативы, фьючерсы
9. **Crypto.com** - Розничный сегмент, visa карты

## 🚀 Быстрый Старт

### Использование в коде:

```python
from core.exchange_manager import get_exchange_manager
import asyncio

async def setup_exchanges():
    manager = get_exchange_manager()
    
    # Добавить биржу
    await manager.add_exchange(
        'binance',
        symbols=['BTC/USDT', 'ETH/USDT', 'SOL/USDT'],
        enabled=True
    )
    
    # Проверить активные биржи
    active = manager.get_active_exchanges()
    print(f"Active exchanges: {active}")
    
    # Получить статистику
    stats = manager.get_statistics()
    print(f"Statistics: {stats}")

asyncio.run(setup_exchanges())
```

## 📋 API Reference

### Добавление биржи

```python
await manager.add_exchange(
    name='binance',           # Имя биржи (обязательно)
    api_key='your_key',       # API ключ (опционально)
    api_secret='your_secret', # API секрет (опционально)
    symbols=['BTC/USDT'],     # Торговые пары (опционально)
    enabled=True,             # Включить сразу (опционально)
    testnet=False,            # Использовать testnet (опционально)
    rate_limit=10            # Лимит запросов/сек (опционально)
)
```

### Удаление биржи

```python
# Полностью удалить биржу из конфигурации
await manager.remove_exchange('binance')
```

```python
# Временно отключить (не удаляет из конфигурации)
await manager.disable_exchange('bybit')

# Включить обратно
await manager.enable_exchange('bybit')
```

## 🔧 Интеграция с main.py

```python
from core.exchange_manager import get_exchange_manager

async def main():
    # Инициализация менеджера бирж
    exchange_manager = get_exchange_manager()
    
    # Добавить дополнительные биржи
    await exchange_manager.add_exchange('binance')
    await exchange_manager.add_exchange('coinbase')
    await exchange_manager.add_exchange('okx')
    
    # Получить активные биржи для бота
    active_exchanges = exchange_manager.get_active_exchanges()
    
    # Использовать в боте
    for exchange in active_exchanges:
        config = exchange_manager.get_exchange_config(exchange)
        # Инициализировать клиенты бирж...
    
    # Периодическая проверка здоровья
    while True:
        health = await exchange_manager.health_check_all()
        if not all(health.values()):
            print(f"Warning: Some exchanges unhealthy: {health}")
        await asyncio.sleep(60)
```

### Горячая замена биржи

```python
async def hot_swap_exchange(old: str, new: str):
    manager = get_exchange_manager()
    
    # Добавить новую
    await manager.add_exchange(new, enabled=True)
    
    # Дождаться инициализации
    await asyncio.sleep(5)
    
    # Удалить старую
    await manager.remove_exchange(old)
    
    print(f"Hot-swapped {old} -> {new}")
```

### Автоматический failover

```python
async def monitor_exchanges():
    manager = get_exchange_manager()
    backup_exchange = 'coinbase'
    
    while True:
        health = await manager.health_check_all()
        
        for exchange, is_healthy in health.items():
            if not is_healthy:
                print(f"⚠️ {exchange} unhealthy!")
                
                # Отключить проблемную
                await manager.disable_exchange(exchange)
                
                # Включить backup
                await manager.enable_exchange(backup_exchange)
        
        await asyncio.sleep(30)
```

### Балансировка нагрузки

```python
def select_best_exchange(manager, symbol: str):
    """Выбрать лучшую биржу для торговли"""
    active = manager.get_active_exchanges()
    
    # Простая стратегия: round-robin
    # В реальности можно учитывать:
    # - Ликвидность
    # - Latency
    # - Комиссии
    # - Объёмы
    
    if not active:
        return None
    
    # Получить биржу с минимальной нагрузкой
    best = active[0]
    return best
```

## 🎓 Best Practices

1. **Проверяйте возвращаемые значения**
```python
success = await manager.add_exchange('binance')
if not success:
    # Обработать ошибку
    logger.error("Failed to add binance")
```

2. **Используйте health checks**
```python
# Регулярно проверяйте здоровье
health = await manager.health_check_all()
```

3. **Graceful shutdown**
```python
async def shutdown():
    manager = get_exchange_manager()
    for exchange in manager.get_active_exchanges():
        await manager.disable_exchange(exchange)
```

4. **Тестируйте на testnet**
```python
await manager.add_exchange('binance', testnet=True)
```

## 🐛 Troubleshooting

### Биржа не добавляется

```python
# Проверьте поддерживается ли биржа
supported = manager.get_supported_exchanges()
```

```python
# Проверьте конфигурацию
config = manager.get_exchange_config('binance')
if not config.enabled:
    await manager.enable_exchange('binance')
```

### Проблемы со здоровьем

```python
# Проверьте статус
health = manager.get_health_status('binance')
if not health:
    # Переинициализировать

    await manager.enable_exchange('binance')
```

### Функция управления биржами:

**Exchange Manager** позволяет:
- ✅ Динамически добавлять биржи
- ✅ Динамически удалять биржи
- ✅ Включать/выключать без перезапуска
- ✅ Горячая замена (hot-swap)
- ✅ Мониторинг здоровья
- ✅ Автоматический failover
- ✅ Балансировка нагрузки
- ✅ Персистентная конфигурация

**Пример использования:**

```python
# В main.py или любом другом месте
from core.exchange_manager import get_exchange_manager

async def setup():
    manager = get_exchange_manager()
    
    # Добавить все 9 бирж
    exchanges = [
        'bybit', 'kucoin', 'htx', 'mexc',
        'binance', 'coinbase', 'gateio', 'okx', 'cryptocom'
    ]
    
    for exchange in exchanges:
        await manager.add_exchange(
            exchange,
            symbols=['BTC/USDT', 'ETH/USDT'],
            enabled=True
        )
    
    print(f"Active exchanges: {manager.get_active_exchanges()}")
    print(f"Statistics: {manager.get_statistics()}")
```

## 🔍 ДРУГИЕ ЧАСТЫЕ ОШИБКИ

### Ошибка: "python: command not found"

**Решение:** Используйте `py` вместо `python`:
```powershell
py main.py
```

### Ошибка: "pip: command not found"

**Решение:** Используйте `py -m pip`:
```powershell
py -m pip install -r requirements.txt
```

### Ошибка: "Access denied" при установке

**Решение:** Установите для пользователя:
```powershell
pip install --user -r requirements.txt
```

### Ошибка: API keys invalid

**Решение:** Проверьте .env файл:
- Нет пробелов вокруг `=`
- Нет кавычек вокруг значений
- Правильные префиксы `ARB_`

**Пример правильного .env:**
```bash
ARB_BYBIT_KEY=UCKrf7a0kYkaIjsYOA
ARB_BYBIT_SECRET=MtgiOtMeCAHsFHQcq0vnoKjLSrz8tRumYfw7
```

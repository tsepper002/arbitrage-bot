## Системные требования

### Минимальные требования:
- **Операционная система**: Windows 11 (рекомендуется), Windows 10, Linux, macOS
- **Процессор**: AMD Ryzen 5 5600H или аналог (4+ ядра)
- **Оперативная память**: 16 GB RAM (минимум 8 GB)
- **Диск**: 1 GB свободного места
- **Интернет**: Стабильное подключение (минимум 10 Мбит/с)

### Программное обеспечение:
- **Python**: версия 3.12 или выше ([скачать](https://www.python.org/downloads/))
- **Git**: для клонирования репозитория ([скачать](https://git-scm.com/downloads))
- **PowerShell**: для Windows (встроен в Windows 11)

## Установка

### Шаг 1: Установка Python

1. Скачайте Python 3.12 с официального сайта: https://www.python.org/downloads/
2. При установке **обязательно** отметьте галочку **"Add Python to PATH"**
3. Проверьте установку, открыв командную строку и выполнив:
   ```bash
   python --version
   ```
   Должно вывести: `Python 3.12.x`

### Шаг 2: Клонирование репозитория

```bash
# Откройте командную строку (cmd) или PowerShell
cd C:\
git clone https://github.com/tsepper002/arbitrage-bot.git
cd arbitrage-bot
```

### Шаг 3: Установка зависимостей

```bash
# В папке arbitrage-bot выполните:
pip install -r requirements.txt
```

Установятся следующие библиотеки:
- `aiohttp` - для HTTP запросов к биржам
- `websockets` - для подключения к WebSocket биржам
- `psutil` - для мониторинга CPU и RAM
- `cryptography` - для подписи API запросов
- `python-dotenv` - для работы с переменными окружения

### Шаг 4: Проверка установки

```bash
python -c "import aiohttp, websockets, psutil; print('✅ Все зависимости установлены')"
```

Если команда выполнилась без ошибок - всё готово к запуску!

## Настройка

### Создание конфигурационного файла

1. Скопируйте шаблон конфигурации:
   ```bash
   copy .env.example .env
   ```
   (в Linux/macOS: `cp .env.example .env`)

2. Откройте файл `.env` в текстовом редакторе (Notepad++, VS Code и т.д.)

### Базовая конфигурация (для тестового режима)

Для первого запуска **ничего менять не нужно**! Бот запустится в тестовом режиме (DRY_RUN).

Основные параметры в `.env`:
```bash
# Режим работы
ARB_DRY_RUN=true  # true = тест, false = реальная торговля

# Минимальная прибыль для торговли (%)
ARB_MIN_NET_ROI_PCT=0.05

# Максимальная сумма одной сделки (USDT)
ARB_MAX_EXPOSURE_USDT=200.0

# Интервал сканирования (секунды)
ARB_SCAN_INTERVAL_SEC=0.5

# Символы для торговли (через запятую)
ARB_SYMBOLS=BTC-USDT,ETH-USDT,SOL-USDT,BNB-USDT,XRP-USDT
```

## Настройка для реальной торговли

> ⚠️ **ВНИМАНИЕ**: Реальная торговля связана с финансовыми рисками! Начинайте с малых сумм.

### Шаг 1: Получение API ключей

Вам нужны API ключи от каждой биржи:

#### Bybit
1. Зайдите на https://www.bybit.com
2. Личный кабинет → API Management → Create New Key
3. Разрешения: **Spot Trading** (Read, Write)
4. Скопируйте **API Key** и **Secret Key**

#### KuCoin
1. Зайдите на https://www.kucoin.com
2. Account → API Management → Create API
3. Разрешения: **Spot Trading**
4. Придумайте **Passphrase** (запомните его!)
5. Скопируйте **API Key**, **Secret Key**, **Passphrase**

#### HTX (Huobi)
1. Зайдите на https://www.htx.com
2. Account → API Management → Create
3. Разрешения: **Trade**
4. Скопируйте **Access Key** и **Secret Key**

#### XT
1. Зайдите на https://www.xt.com
2. API Management → Create New Key
3. Разрешения: **Spot Trading**
4. Скопируйте **API Key** и **Secret Key**

#### MEXC
1. Зайдите на https://www.mexc.com
2. API Management → Create New Key
3. Разрешения: **Spot Trading**
4. Скопируйте **API Key** и **Secret Key**

### Шаг 2: Внесение API ключей в конфигурацию

Откройте файл `.env` и заполните ключи:

```bash
# Bybit
ARB_BYBIT_KEY=ваш_api_ключ_bybit
ARB_BYBIT_SECRET=ваш_secret_ключ_bybit

# KuCoin
ARB_KUCOIN_KEY=ваш_api_ключ_kucoin
ARB_KUCOIN_SECRET=ваш_secret_ключ_kucoin
ARB_KUCOIN_PASSPHRASE=ваша_парольная_фраза_kucoin

# HTX
ARB_HTX_KEY=ваш_access_key_htx
ARB_HTX_SECRET=ваш_secret_key_htx

# XT
ARB_XT_KEY=ваш_api_ключ_xt
ARB_XT_SECRET=ваш_secret_ключ_xt

# MEXC
ARB_MEXC_KEY=ваш_api_ключ_mexc
ARB_MEXC_SECRET=ваш_secret_ключ_mexc
```

### Шаг 3: Настройка лимитов риска

**Обязательно настройте лимиты** перед реальной торговлей:

```bash
# Максимальный убыток за день ($)
ARB_MAX_DAILY_LOSS=50.0

# Максимальный убыток за час ($)
ARB_MAX_HOURLY_LOSS=20.0

# Максимальный размер одной сделки ($)
ARB_MAX_EXPOSURE_USDT=200.0

# Минимальный баланс на бирже для торговли ($)
ARB_MIN_BALANCE_PER_EXCHANGE=20.0
```

### Шаг 4: Пополнение балансов

Переведите USDT на каждую биржу:
- **Рекомендация**: Начните с $100-200 на каждую биржу
- **Минимум**: $50 на биржу (указан в `ARB_MIN_BALANCE_PER_EXCHANGE`)

### Шаг 5: Проверка конфигурации

```bash
python settings.py
```

Проверьте, что:
- ✅ Все API ключи загружены
- ✅ Режим DRY_RUN = True (пока!)
- ✅ Лимиты риска настроены

## Запуск в боевом режиме

### ⚠️ ПОСЛЕДНЯЯ ПРОВЕРКА

Перед переключением в боевой режим:
1. ✅ Проверены все API ключи
2. ✅ Настроены лимиты риска
3. ✅ Пополнены балансы на биржах
4. ✅ Бот тестировался в DRY_RUN режиме минимум 24 часа

### Переключение в боевой режим

Откройте `.env` и измените:
```bash
ARB_DRY_RUN=false  # Включение реальной торговли
```

### Запуск

```bash
python main.py
```

Вы увидите предупреждение:
```
=== Arbitrage Bot Configuration (ENHANCED) ===
Execution Mode: 🔴 LIVE TRADING (Real money!)
...
```

### Что произойдёт

Бот начнёт:
1. Сканировать рынки каждые 0.5 секунды
2. При обнаружении прибыльного арбитража (ROI > 0.05%):
   - Проверит балансы на биржах
   - Проверит лимиты риска
   - Выполнит **реальную покупку** на одной бирже
   - Выполнит **реальную продажу** на другой бирже
3. Логировать все сделки

### Мониторинг сделок

Логи сделок записываются в:
- **Консоль**: вывод в реальном времени
- **arbs.csv**: все обнаруженные возможности
- **trades.csv**: все выполненные сделки
- **bot_state.json**: текущее состояние (P&L, балансы)

## Автоматический запуск (24/7)

### Для Windows 11

Используйте встроенный watchdog для автоматического перезапуска при сбоях:

#### Шаг 1: Настройка PowerShell

Откройте PowerShell от имени администратора:
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

#### Шаг 2: Тест watchdog

```powershell
cd C:\arbitrage-bot
.\watchdog.ps1
```

Watchdog будет:
- Запускать бота
- Проверять файл `heartbeat.txt` каждые 30 секунд
- Перезапускать бота если heartbeat старше 120 секунд
- Логировать всё в `watchdog.log`

#### Шаг 3: Настройка автозапуска через Task Scheduler

1. Откройте **Task Scheduler** (Планировщик заданий)
2. Нажмите **Create Task** (Создать задачу)

**Вкладка General:**
- Name: `Arbitrage Bot Watchdog`
- ✅ Run whether user is logged on or not
- ✅ Run with highest privileges

**Вкладка Triggers:**
- New → Begin the task: **At startup**
- Delay task for: 1 minute

**Вкладка Actions:**
- New → Action: **Start a program**
- Program: `powershell.exe`
- Arguments: `-ExecutionPolicy Bypass -File "C:\arbitrage-bot\watchdog.ps1"`
- Start in: `C:\arbitrage-bot`

**Вкладка Conditions:**
- ❌ СНЯТЬ галочку "Start the task only if the computer is on AC power"

**Вкладка Settings:**
- ✅ If the task fails, restart every: 1 minute
- ✅ Attempt to restart up to: 3 times

3. Нажмите **OK** и введите пароль Windows

4. **Тест**: Правой кнопкой на задаче → Run → Проверьте `watchdog.log`

5. **Перезагрузите компьютер** - бот должен запуститься автоматически!

### Для Linux (systemd)

Создайте systemd service:

```bash
sudo nano /etc/systemd/system/arbitrage-bot.service
```

Вставьте:
```ini
[Unit]
Description=Cryptocurrency Arbitrage Bot
After=network.target

[Service]
Type=simple
User=ваш_пользователь
WorkingDirectory=/home/ваш_пользователь/arbitrage-bot
Environment="PATH=/usr/local/bin:/usr/bin:/bin"
ExecStart=/usr/bin/python3 main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Активируйте:
```bash
sudo systemctl daemon-reload
sudo systemctl enable arbitrage-bot
sudo systemctl start arbitrage-bot
sudo systemctl status arbitrage-bot  # Проверка
```

## Решение проблем

### Проблема: "ModuleNotFoundError: No module named 'aiohttp'"

**Решение**:
```bash
pip install -r requirements.txt
```

### Проблема: WebSocket не подключается

**Возможные причины**:
1. Блокировка брандмауэром/антивирусом
2. Проблемы с интернетом
3. Биржа блокирует ваш IP

**Решение**:
```bash
# Проверьте интернет
ping google.com

# Отключите антивирус временно
# Попробуйте использовать VPN
```

### Проблема: "API authentication failed"

**Причины**:
1. Неверные API ключи
2. IP адрес не в белом списке (для некоторых бирж)
3. Недостаточные разрешения у API ключа

**Решение**:
1. Проверьте правильность ключей в `.env`
2. В настройках API на бирже добавьте ваш IP в whitelist
3. Убедитесь, что API ключ имеет права "Spot Trading"

### Проблема: "Insufficient balance"

**Решение**:
```bash
# Проверьте балансы через настройки
python -c "from core.state_manager import StateManager; sm = StateManager(); sm.load_state(); print(sm.state.get('balances', {}))"

# Пополните биржи или уменьшите MAX_EXPOSURE_USDT в .env
```

### Проблема: Высокая нагрузка на CPU

**Решение**:
Увеличьте интервалы сканирования в `.env`:
```bash
ARB_SCAN_INTERVAL_SEC=1.0          # Было 0.5
ARB_SYMBOL_COOLDOWN_SEC=10.0       # Было 5.0
ARB_CPU_HIGH_THRESHOLD=50.0        # Понизить порог
```

### Проблема: Бот не находит арбитраж

**Это нормально!** Арбитраж - редкое явление. Возможные причины:
1. Низкая волатильность рынка
2. Высокая конкуренция (другие боты быстрее)
3. Слишком высокий `MIN_NET_ROI_PCT`

**Решение**:
```bash
# Понизьте минимальную прибыль (осторожно!)
ARB_MIN_NET_ROI_PCT=0.03  # Было 0.05

# Увеличьте количество символов
ARB_SYMBOLS=BTC-USDT,ETH-USDT,SOL-USDT,BNB-USDT,XRP-USDT,DOGE-USDT,LTC-USDT,ADA-USDT
```

### Логи и диагностика

Важные файлы для диагностики:
- `bot_state.json` - текущее состояние бота
- `arbs.csv` - все найденные возможности
- `trades.csv` - все выполненные сделки
- `heartbeat.txt` - последний heartbeat (для watchdog)
- `watchdog.log` - логи watchdog (если используется)

Включите подробное логирование:

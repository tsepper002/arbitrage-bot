# 🔑 Где вводить API ключи и настройки

## 📍 Быстрый ответ

**API ключи и настройки вводятся в файл `.env` в корневой папке проекта.**

```
arbitrage-bot/
├── .env          ← ЗДЕСЬ! (вы создаёте этот файл)
├── .env.example  ← Шаблон (копируйте отсюда)
├── main.py
├── settings.py
└── ...
```

---

## 📝 Пошаговая инструкция

### Шаг 1: Найдите файл `.env.example`

Откройте папку с ботом:
```bash
cd C:\arbitrage-bot
```

Вы увидите файл `.env.example` - это **шаблон** с примерами.

### Шаг 2: Создайте файл `.env`

Скопируйте шаблон в новый файл `.env`:

**Windows (Command Prompt):**
```cmd
copy .env.example .env
```

**Windows (PowerShell):**
```powershell
Copy-Item .env.example .env
```

**Linux/macOS:**
```bash
cp .env.example .env
```

### Шаг 3: Откройте файл `.env` для редактирования

Используйте любой текстовый редактор:

**Windows:**
```cmd
notepad .env
```
или
```cmd
code .env    # VS Code
```

**Linux/macOS:**
```bash
nano .env
# или
vim .env
# или
code .env    # VS Code
```

### Шаг 4: Вставьте свои API ключи

Найдите строки с `your_*_here` и замените их на реальные ключи:

#### ❌ БЫЛО (в .env.example):
```bash
ARB_BYBIT_KEY=your_bybit_api_key_here
ARB_BYBIT_SECRET=your_bybit_api_secret_here
```

#### ✅ СТАЛО (в .env):
```bash
ARB_BYBIT_KEY=aBcDeFgHiJkLmNoPqRsTuVwXyZ123456
ARB_BYBIT_SECRET=xYz987654321AbCdEfGhIjKlMnOpQrStUvWx
```

## 📂 Где находится файл `.env`?

### Проверка расположения:

```bash
# Windows
dir .env

# Linux/macOS
ls -la .env
```

Файл `.env` должен быть **в той же папке**, где находятся:
- `main.py`
- `settings.py`
- `requirements.txt`

### Правильная структура:
```
C:\arbitrage-bot\          ← Корневая папка проекта
├── .env                   ← ВАШ ФАЙЛ С КЛЮЧАМИ (создаёте сами)
├── .env.example           ← Шаблон (не редактируйте!)
├── .gitignore             ← .env автоматически игнорируется Git
├── main.py
├── settings.py
├── requirements.txt
├── ИНСТРУКЦИЯ.md
├── core/
├── exchanges/
└── ...
```

## 🎯 Как бот читает настройки?

Бот автоматически загружает переменные из файла `.env` при запуске:

1. **Запускаете бота**: `python main.py`
2. **Python ищет файл `.env`** в текущей папке
3. **Загружает все переменные** начинающиеся с `ARB_`
4. **Использует их в коде** через `os.getenv("ARB_BYBIT_KEY")`

### Порядок приоритета настроек:

1. 🥇 **Системные переменные окружения** (если задали вручную)
2. 🥈 **Файл `.env`** (обычный способ)
3. 🥉 **Значения по умолчанию** в `settings.py`

```bash

```

## 🔒 Безопасность файла `.env`

### ⚠️ ВАЖНО:

1. **Никогда не публикуйте файл `.env`** на GitHub или где-либо ещё
2. Файл `.env` автоматически добавлен в `.gitignore`
3. Храните резервную копию `.env` в безопасном месте
4. Не отправляйте `.env` по email или мессенджерам

### Проверка .gitignore:

```bash
# Проверьте, что .env в .gitignore
cat .gitignore | grep .env
```

Должно вывести:
```
.env
```

## 🆘 Частые проблемы

### Проблема 1: "FileNotFoundError: .env file not found"

**Решение**: Создайте файл `.env` из шаблона:
```bash
copy .env.example .env
```

### Проблема 2: "API authentication failed"

**Причины**:
- Неправильно скопированы ключи (лишние пробелы)
- Ключи истекли или отозваны
- IP адрес не в белом списке биржи

**Решение**:
1. Проверьте, что нет пробелов в начале/конце ключей
2. Зайдите на биржу и проверьте статус API ключей
3. Создайте новые ключи если нужно

### Проблема 3: Бот не видит ключи

**Проверьте**:
```bash
# Windows
type .env | findstr ARB_BYBIT_KEY

# Linux/macOS
grep ARB_BYBIT_KEY .env
```

Должно показать вашу строку с ключом.

### Проблема 4: Редактор не видит файл `.env`

На Windows файлы начинающиеся с точки могут быть скрыты.

**Решение**:
1. В Проводнике → Вид → Показать скрытые файлы
2. Или используйте команду `dir /a` чтобы увидеть все файлы

## 📱 Настройка Telegram (опционально)

Если хотите получать уведомления:

### 1. Создайте бота

1. Откройте Telegram
2. Найдите **@BotFather**
3. Отправьте команду: `/newbot`
4. Следуйте инструкциям
5. Скопируйте токен (например: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Получите Chat ID

1. Напишите боту любое сообщение
2. Откройте в браузере:
   ```
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
   ```
3. Найдите `"chat":{"id":123456789}` - это ваш Chat ID

### 3. Добавьте в .env

```bash
ARB_TELEGRAM_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
ARB_TELEGRAM_CHAT_ID=123456789
```

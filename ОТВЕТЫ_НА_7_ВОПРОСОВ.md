## 1. BYBIT 403 ERROR

### ❓ Вопрос
"по поводу бибит, ключ 100% рабочий, в чем могут быть еще проблемы?"

### ✅ Ответ

Если API ключ точно рабочий, проблема 403 может быть вызвана:

#### Причина 1: IP Whitelist (САМАЯ ЧАСТАЯ)
**Что это:** Bybit позволяет ограничить доступ к API только с определенных IP адресов

**Решение:**
1. Зайти на Bybit → API Management
2. Найти ваш API key
3. Проверить "IP Restriction"
4. Добавить ваш текущий IP: `77.110.114.174`
5. Или отключить IP restriction (менее безопасно)

#### Причина 2: API Permissions
**Что это:** API ключ может не иметь прав на SPOT wallet

**Решение:**
1. Проверить permissions вашего API key
2. Должны быть включены:
   - ✅ Read (чтение балансов)
   - ✅ Trade (опционально)
3. Если нет - создать новый key с правами на SPOT

#### Причина 3: Rate Limiting
**Что это:** Слишком много запросов в секунду

**Решение:**
- Код уже имеет rate limiting
- Но если тестировали вручную - может быть temporary ban
- Подождать 5-10 минут

#### Причина 4: Geographic Restriction
**Что это:** Некоторые страны блокируются Bybit

**Решение:**
- Проверить доступен ли Bybit в вашем регионе
- VPN может помочь (но нарушает ToS)

#### Причина 5: HTML Response
**Что показывает ошибка:** "Attempt to decode JSON with unexpected mimetype: text/html"

**Означает:** Сервер вернул HTML страницу (обычно error page) вместо JSON

**Обычно это:**
- IP блокировка
- API endpoint недоступен
- Временная проблема на стороне Bybit

### 🔧 Диагностика

Добавлена детальная диагностика в код:

```python
if e.status == 403:
    logger.error("❌ Bybit 403 - Possible causes:")
    logger.error("   1. IP not in whitelist")
    logger.error("   2. API key lacks SPOT permissions")
    logger.error("   3. Geographic restriction")
    logger.error("   4. Rate limit exceeded")
```

### 💡 Рекомендации

**Best Practice:**
1. Создать НОВЫЙ API key специально для бота
2. Дать минимальные права (только Read для тестирования)
3. Добавить ваш IP в whitelist
4. Тестировать сначала с small permissions
5. Расширять права по мере необходимости
